# Change Stack

[English](README.md) · **Русский**

`cstack` — локальный инструмент для ревью pull request. Он открывает изменения в браузере, разбивает их на логические слои в порядке чтения и объясняет каждый слой с помощью вашей OpenAI-совместимой модели. Код, анализ и состояние ревью хранятся в памяти на вашем компьютере и удаляются при завершении процесса.

## Возможности

- **Слои** — модель группирует изменённые строки в логические шаги, упорядоченные так, чтобы основа шла первой. Один файл может входить в несколько слоёв.
- **Группы и зависимости** — независимые части работы, ссылки «опирается на» и полноэкранная карта слоёв (`G`).
- **Заметки к частям** — крупные слои разбиты на части, над каждой частью в коде стоит однострочная заметка (`N` скрывает их).
- **Категории** — короткая метка у каждого слоя, например «Backend fix» или «UI change».
- **Весь файл сбоку** — если слой показывает часть файла, полный diff открывается в боковой панели с изменяемой шириной.
- **Инструменты чтения** — split/unified diff, поиск (`⌘/Ctrl K`), навигация с клавиатуры, соседний контекст, поиск символов, прогресс просмотренных файлов, четыре темы GitHub/GitLab.

## Установка

В релизах есть автономный бинарник для **macOS на Intel (x86_64)**; Bun и Node.js не нужны. Скачайте `cstack-vX.Y.Z-macos-x64.tar.gz` и `SHA256SUMS` из [Releases](https://github.com/Neat-Snap/change-stack/releases), затем:

```sh
shasum -a 256 -c SHA256SUMS
tar -xzf cstack-vX.Y.Z-macos-x64.tar.gz
mkdir -p ~/.local/bin && cp cstack-vX.Y.Z-macos-x64/cstack ~/.local/bin/
cstack --version
```

Бинарник не подписан и не нотарифицирован. Если macOS блокирует запуск, разрешите его в **Системные настройки → Конфиденциальность и безопасность**.

## Использование

```sh
cstack                                  # пошаговая настройка, затем вставьте ссылку на ревью
cstack 'https://gitlab.example/group/project/-/merge_requests/123'
cstack --demo                           # пример ревью без обращения к сети
cstack --help                           # все параметры
```

При первом запуске CLI запросит Git-токен с правами чтения, а также базовый URL, идентификатор модели и API-ключ. Не закрывайте терминал во время ревью; `Ctrl+C` останавливает локальный сервер.

Настройки и ключи хранятся в `~/.change-stack/` (открытым текстом, права `0600`). Чтобы удалить их, удалите этот каталог.

## Разработка

Нужен Bun 1.3.14.

```sh
bun install --frozen-lockfile
bun run demo          # запустить UI с примером данных
bun run typecheck && bun run test
bun run build         # dist/cstack для текущей платформы
bun run test:tls && bun run test:ui
```
