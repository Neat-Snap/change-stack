Change Stack — локальный просмотр GitLab merge request и GitHub pull request.

В этом выпуске доступен автономный `cstack` для **macOS на Intel (x86_64)**. Bun и Node.js устанавливать не требуется. Архив содержит бинарник, русскую инструкцию и уведомления о лицензиях. `SHA256SUMS` позволяет проверить скачанный архив.

Начните с `cstack`: CLI предложит выбрать Git-сервис, вставить ссылку на ревью, создать токен в браузере и подключить внутреннюю модель. Следующие ревью открываются командой `cstack '<ссылка>'`.

Подробная установка, настройка корпоративных сертификатов и использование: [README](https://github.com/Neat-Snap/change-stack#readme).

Контейнер для Linux amd64 публикуется в `ghcr.io/neat-snap/change-stack` с тем же тегом версии. Доступ определяется настройками приватного репозитория и пакета.

Бинарник не подписан Developer ID и не нотарифицирован Apple. Поддержка Apple Silicon в этом выпуске не заявлена.
